# 个人工作生活专属 App — 产品需求文档（PRD）

> 版本：V1.0  
> 创建日期：2026-11-07  
> 状态：第一版需求确认

---

## 1. 产品目标和使用场景

### 1.1 产品目标

做一个**只供个人使用**的工作生活管理工具，在浏览器里本地运行，把分散在各处的待办、健康、饮食、知识、物品、开发项目等信息统一管理起来。数据完全保存在本地电脑，不联网、不登录、不上云。

### 1.2 使用场景

- **早晨打开**：看首页总览，知道今天要做什么，有什么截止提醒
- **工作中**：在开发工作模块记录 Bug、需求、技术笔记，写开发日志
- **运动前后**：健康模块记录训练内容和感受，查看体重趋势
- **买菜/做饭前**：饮食模块看买菜清单和常用菜谱，记录饮食
- **遇到问题时**：在问题思考模块记录问题和解决方案，方便以后查阅
- **整理东西时**：物品收纳模块查东西放哪了，物品使用说明查保质期和用法
- **需要梳理思路时**：信息整理模块用思维导图或卡片整理信息，标记重要性
- **每周初**：每周计划模块安排一周的任务
- **每天结束**：任务汇总看当天完成了多少、时间花在哪了，未完成的自动顺延
- **定期备份**：导出数据文件存到电脑上，防止浏览器清缓存丢数据

### 1.3 目标用户

用户只有一个人——开发者本人。不需要考虑多人协作、权限管理、账号系统等问题。

### 1.4 核心原则

- **每个模块有自己的特色**，不能只是同一个任务列表换个名字
- **纯本地运行**，打开 HTML 文件就能用，不需要服务器、不需要安装
- **数据安全**，刷新、关闭、重启都不丢，支持手动备份恢复
- **操作简单**，尽量就地编辑、自动保存，减少弹窗和确认步骤

## 2. 整体页面框架和导航结构

### 2.1 整体布局

采用**左侧导航栏 + 顶部工具栏 + 右侧主内容区**的三栏布局：

```
┌───────────────────────────────────────────────────────┐
│  顶部工具栏（快速备忘入口 · 提醒角标 · 设置入口）        │
├────────┬──────────────────────────────────────────────┤
│        │                                              │
│ 左侧   │              主内容区                          │
│ 导航栏  │         （当前模块的页面内容）                 │
│        │                                              │
│        │                                              │
└────────┴──────────────────────────────────────────────┘
```

### 2.2 左侧导航栏

导航栏按功能分组，当前选中的模块高亮显示，有未处理事项的模块显示红色数字角标。

| 分组 | 模块 | 说明 |
|------|------|------|
| 总览 | 首页总览 | 入口页，显示各模块摘要 |
| 计划与任务 | 每周计划 · 任务汇总 | 时间维度的任务管理 |
| 生活管理 | 健康计划 · 饮食计划 · 物品使用说明 · 物品收纳 | 生活相关 |
| 知识与工作 | 问题思考 · 信息整理 · 开发工作 | 知识管理和开发 |
| 系统 | 数据与设置 | 备份恢复、偏好设置 |

### 2.3 顶部工具栏

- 左侧：App 名称 / 当前页面标题
- 右侧：快速备忘输入框、提醒铃铛（显示待处理提醒总数）、设置图标

## 5. 每个模块第一版最必要的数据和操作

### 5.1 首页总览

**数据：**
- 本周未完成任务列表（从每周计划和任务汇总读取）
- 截止日期提醒列表（从物品使用说明、开发工作、每周计划读取）
- 各模块的待处理数量统计
- 健康数据摘要（本周运动次数、最新体重）

**操作：**
- 点击摘要卡片跳转到对应模块
- 快速备忘输入（回车保存到任务汇总的"待分类"）
- 切换查看不同维度的摘要（暂只做默认视图）

### 5.2 每周计划

**数据字段：**
- 任务 ID、标题、备注
- 所属日期（周几）
- 优先级（高/中/低）
- 预计时长
- 完成状态
- 来源模块（每周计划 / 其他模块同步过来的）

**操作：**
- 新增/编辑/删除任务
- 勾选完成
- 拖拽任务到不同天调整日期
- 周切换（上一周 / 本周 / 下一周）
- 一键复制上周未完成任务到本周

### 5.3 健康计划

**数据字段：**

运动记录：
- 记录 ID、日期、运动项目、总时长
- 训练感受/实际结果（文字）
- 动作列表（每个动作：名称、组数、次数/重量、休息时间）

体重记录：
- 记录 ID、日期、体重数值

动作库：
- 动作 ID、名称、说明、目标部位、默认组次休息时间

目标：
- 运动频率目标（每周几次）
- 体重目标（目标体重）

**操作：**
- 新增/编辑/删除运动记录
- 新增/编辑/删除体重记录
- 管理动作库（增删改）
- 查看体重趋势折线图（7天/30天/90天）
- 查看本周训练次数统计
- 设置和查看目标达成进度

### 5.4 饮食计划

**数据字段：**

每日饮食：
- 记录 ID、日期、餐次（早/中/晚/加餐）
- 食物列表（每项：食品名、大致数量）
- 备注

买菜清单：
- 物品 ID、名称、数量、是否已购买

常用菜谱：
- 菜谱 ID、名称、食材列表、做法说明、营养大致估算

食品营养库：
- 食品 ID、名称、分类
- 每 100g 营养数据：热量、蛋白质、碳水、脂肪（大致值）

**操作：**
- 记录每日饮食（从食品营养库搜索选择食品）
- 管理买菜清单（勾选已购买、从菜谱一键添加食材）
- 管理常用菜谱（增删改）
- 管理食品营养库（增删改）
- 查看当日大致营养摄入统计

### 5.5 问题思考（知识库）

**数据字段：**
- 问题 ID、标题、问题描述
- 解决方案/答案（支持多行文本）
- 分类（支持多级分类）
- 重要性（★/★★/★★★ 三级）
- 标签
- 创建时间、更新时间

**操作：**
- 新增/编辑/删除问题记录
- 按分类浏览
- 关键词搜索（搜索标题和内容）
- 标记重要性（标星）
- 管理分类（增删改，支持嵌套）

### 5.6 信息整理

**数据字段：**
- 信息 ID、标题、内容
- 分类
- 重要性等级（普通 / 重要 / 非常重要）
- 是否置顶
- 标签
- 颜色标记
- 思维导图节点数据（节点 ID、父节点、位置坐标、内容）

**操作：**
- 新增/编辑/删除信息卡片
- 按分类筛选
- 按重要性/时间排序
- 标记重要性、置顶、颜色标记
- 搜索
- **思维导图视图**：
  - 创建节点、编辑节点内容
  - 拖拽调整节点位置
  - 建立父子节点关系（连线）
  - 展开/收起子节点
  - 从卡片视图一键生成思维导图（卡片作为节点）
  - 切换卡片视图 / 思维导图视图

### 5.7 开发工作

**数据字段：**

项目：
- 项目 ID、项目名称、描述
- 本地项目目录路径
- 文档路径
- 代码仓库地址
- 创建时间

项目内条目（Bug / 需求 / 功能 / 技术问题 共用结构）：
- 条目 ID、类型（Bug/需求/功能/技术问题）
- 标题、详细描述
- 状态（待处理 / 进行中 / 已完成 / 已关闭）
- 优先级（高/中/低）
- 所属模块/分类
- 创建时间、更新时间

开发日志：
- 日志 ID、日期时间、内容

技术笔记：
- 笔记 ID、标题、内容、分类标签

下一步行动：
- 行动 ID、内容、关联条目

**操作：**
- 管理多个项目（增删改）
- 在项目内切换不同类型的条目（Bug/需求/功能/技术问题）
- 新增/编辑/删除条目，修改状态和优先级
- 写开发日志
- 管理技术笔记
- 设置和查看下一步行动
- 编辑项目关联信息（本地目录、文档、仓库地址）

### 5.8 物品使用说明

**数据字段：**
- 物品 ID、名称、分类
- 使用说明
- 注意事项
- 购买日期
- 保质期（到期日期）
- 当前库存数量
- 库存提醒阈值（低于此数量提醒补货）
- 保质期提醒提前天数（默认 7 天）

**操作：**
- 新增/编辑/删除物品
- 按分类筛选
- 搜索
- 查看"提醒"列表（快过期的 + 库存不足的）
- 调整库存数量（使用/补货）

### 5.9 物品收纳

**数据字段：**
- 物品 ID、名称
- 存放位置（支持多级，如"储物间→上层架子→左边盒子"）
- 数量
- 备注

**操作：**
- 新增/编辑/删除物品记录
- 表格形式展示
- 按名称或位置搜索
- 按位置分组查看
- 导出为 CSV

### 5.10 任务汇总

**数据字段：**
- 任务 ID、标题、描述
- 来源模块（每周计划 / 健康计划 / 开发工作 / 物品使用说明 / 待分类）
- 来源 ID（关联到源模块的具体条目）
- 日期
- 具体时间段（开始时间 - 结束时间）
- 预计时长（分钟）
- 优先级（高/中/低）
- 状态（待处理 / 进行中 / 已完成 / 延期 / 已取消）
- 是否顺延标记（从昨天顺延过来的）
- 排序顺序（同一天内的手动排序）

**操作：**
- 按日期查看（周一到周日 Tab 切换）
- 新增/编辑/删除任务
- 勾选完成 / 标记延期 / 标记取消
- **拖拽排序**（同一天内调整顺序）
- **跨天拖拽**（把任务拖到另一天）
- **跨模块拖拽移动**（把事项卡从一个模块拖到另一个模块，改变归属）
- 未完成任务自动顺延到下一天（可配置是否开启）
- 查看当日完成率
- 查看当日时间分配统计（按模块分类的占比）
- 筛选（按来源模块、按优先级、按状态）

### 5.11 数据与设置

**数据字段：**
- 主题色
- 每周第一天（周一/周日）
- 物品保质期提醒提前天数
- 任务未完成是否自动顺延
- 数据版本号

**操作：**
- 导出全部数据为 JSON 文件（下载到电脑）
- 从 JSON 文件导入恢复数据
- 清空所有数据（二次确认）
- 修改偏好设置
- 查看数据统计（各模块条目数、总数据量）

## 6. 首页、任务汇总和各模板之间的关系

### 6.1 数据流向

```
各模块产生任务/提醒
    │
    ├── 每周计划 ──┐
    ├── 健康计划 ──┤
    ├── 开发工作 ──┤
    ├── 物品使用 ──┤
    ├── 快速备忘 ──┴──→ 任务汇总（统一管理所有任务）
                            │
                            └──→ 首页总览（摘要展示）
```

### 6.2 跳转关系

- **首页 → 各模块**：点击任何摘要卡片跳转到对应模块
- **各模块 → 任务汇总**：模块内的待办事项可以在任务汇总中统一查看和管理
- **任务汇总 → 各模块**：点击任务的来源标签可以跳转到源模块的对应条目
- **左侧导航**：任意模块间自由切换

### 6.3 事项卡拖拽移动关系

事项卡（任务/待办条目）可以在模块之间拖拽移动：

| 源模块 | 可拖到 | 说明 |
|--------|--------|------|
| 每周计划 | 任务汇总、其他日期 | 调整日期或归入任务汇总重新分类 |
| 任务汇总 | 其他日期、其他模块 | 改变日期或改变归属模块 |
| 开发工作 | 任务汇总 | 把 Bug/需求转为待办任务 |
| 问题思考 | 信息整理 | 把知识条目转为信息卡片 |
| 信息整理 | 问题思考 | 把信息卡片转为知识库条目 |
| 快速备忘（待分类） | 任意模块 | 把待分类事项归入具体模块 |

拖拽规则：
- 拖拽时显示半透明的事项卡预览
- 悬停在可接收的区域时高亮提示
- 松开鼠标后完成移动，数据归属更新
- 支持撤销（误操作后可恢复）

## 7. 本地数据文件、备份和恢复要求

### 7.1 数据存储方式

- **日常存储**：使用浏览器 IndexedDB 存储所有数据，刷新、关闭页面、重启电脑都不会丢失
- **备份文件**：用户手动导出时，生成一个 JSON 文件下载到本地电脑
- **恢复**：用户选择本地备份文件上传，导入后覆盖当前数据

### 7.2 备份文件格式

- 格式：JSON
- 文件名建议：`personal-app-backup-YYYYMMDD-HHmmss.json`
- 内容：包含所有模块的全部数据 + 数据版本号 + 导出时间

### 7.3 导入导出规则

- **导出**：一键导出全部数据，生成 JSON 文件供用户下载保存
- **导入**：选择 JSON 文件，解析验证后导入
  - 导入前提示"导入将覆盖当前所有数据，是否继续？"
  - 文件格式错误时给出明确提示
  - 版本不兼容时给出警告，允许强制导入但提示可能有问题
- **清空数据**：需要二次确认，确认后清空所有数据，不可恢复

### 7.4 数据安全

- 所有数据只存在用户自己的浏览器和导出的文件中
- 不上传任何服务器
- 不做数据加密（第一版）
